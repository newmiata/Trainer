Trainer / Модуль — встановлення через GitHub Pages

Файли: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png

1. На github.com відкрийте репозиторій Trainer -> Add file -> Upload files.
2. Завантажте ФАЙЛИ з цієї папки (не саму папку). Файли з тими самими назвами замінять старі.
3. Commit changes. Через 1-2 хвилини сайт оновиться: https://ВАШ-ЛОГІН.github.io/Trainer/
4. На телефоні закрийте додаток повністю й відкрийте знову (за потреби двічі).
